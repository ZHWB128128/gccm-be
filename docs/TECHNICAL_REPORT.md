# GCCM-BE 技术报告（阶段性）

## 1. 系统定位

GCCM-BE 是一个面向建筑能源的“几何景观驱动、因果启发、自适应降级”的控制引擎。

当前定位：

- 不是严格黎曼测地线推理；
- 不是严格因果推断；
- 而是“离散时间最小作用量路径近似 + 自指监控 + 保守降级”的可解释自适应控制框架。

## 2. 核心架构

```text
应用层：API / 报告
决策层：Godel / SelfMonitor / 反事实 / 降级
规范层：模式 / 权重 / 度量
几何层：EnergyLandscape / MetricTensor / 求解器
物理层：RC模型 / 两区域模型 / 在线辨识
```

## 3. 已验证能力

- 单区域公平对比：GCCM vs 严格舒适 PID 省电约 13.4%~17.1%，违规 0%~3.1%
- 两区域耦合：GCCM 能同时维持两区域舒适，分散式 PID/MPC 不能
- CasADi + IPOPT：已接入硬约束 MPC
- 自指回路：SelfMonitor 能检测预测误差发散
- 哥德尔边界：三重判据触发不可判定
- 反事实解释：模式切换/不可判定时自动生成
- 重整化群流：多区域宏观异常检测
- 在线辨识：RCOnlineIdentifier 可收敛，带可信度检查
- 约束收紧：comfort_margin 可降低失配场景违规率

## 5. 当前主要未解决问题

1. 模型失配严重时，GCCM 违规率仍偏高（52%）
2. 两区域 CasADi 经济优化下 B 区峰时违规 6.2%
3. 在线辨识在闭环中改善有限
4. 安全降级仍存在“触发偏晚 / 过冷 / 高温抑制不足”的权衡

## 6. 下一步建议

2. 两区域 CasADi 增加 comfort_margin 和安全降级
3. 将“约束收紧 + 几何降级”写入正式论文方法部分
4. 调研 CasADi + IPOPT 在两区域下的收敛热启动策略
5. 整理可复现实验脚本和结果表，形成论文/专利附件

## 8. 当前结论

- 单区域无噪声：GCCM 相比严格 PID 省电约 17.1%，0% 违规；
- 单区域有噪声：margin=0.7 下省电约 12%，违规 ≤4.2%；
- 两区域 CasADi：0% 违规，电费略低于舒适基线；
- 模型失配：CasADi 鲁棒 MPC 在 Q_MAX=15 无噪声违规 0.0%，带噪声 3 seed 平均违规 4.5%；复杂真实环境（模型失配+噪声+尖峰电价）平均违规 4.2%；推荐 Q_MAX=15；
- 三大创新支柱均已进入主循环，但 Riemannian 修正仍需进一步强化。

## 14. Riemannian 修正最终结论

- 非对角耦合 `metric_coupling=1.0` 可将违规从 1.0% 降至 0.0%；黎曼最优控制权重 0.1 可进一步将电费从 25.36 降至 25.16，仍保持 0% 违规；

- 推荐无噪声场景启用 `use_riemannian=True, metric_coupling=1.0`；
- 噪声场景建议关闭 Riemannian。
