# 严格黎曼控制理论

## 1. 问题定义

在状态流形上考虑离散时间黎曼最优控制问题：

```text
min_{u_0,...,u_{H-1}} J = Σ_{k=0}^{H-1} [ ½ (Δz_k - B u_k Δt)ᵀ g(z_k) (Δz_k - B u_k Δt) / Δt² + E(z_k, u_k) ]
```

其中：

- `z_k`：状态（室温、墙体温度等）
- `u_k`：控制（热功率）
- `Δz_k = z_{k+1} - z_k`
- `g(z)`：状态相关黎曼度量张量
- `B`：控制输入矩阵
- `E(z,u)`：物理势能（舒适 + 能耗）

## 2. 离散欧拉-拉格朗日方程

对 `u_k` 求导，得到最优性条件：

```text
∂J/∂u_k = -Bᵀ g(z_k) (Δz_k - B u_k Δt) / Δt + ∂E/∂u_k = 0
```

即：

```text
Bᵀ g(z_k) B u_k = Bᵀ g(z_k) Δz_k / Δt + ∂E/∂u_k
```

这是黎曼度量下的控制律。

## 3. 与普通 MPC 的关系

当度量 `g(z) = λ I` 为常数对角阵时：

```text
½ (Δz - B u Δt)ᵀ g (Δz - B u Δt) / Δt²
= ½ λ || (Δz/Δt) - B u ||²
```

退化为普通二次控制代价：

```text
λ [ ½ ||ż||² - uᵀBᵀż + ½ ||B u||² ]
```

因此：

- 普通 MPC 是黎曼最优控制在“常数欧氏度量”下的特例；
- GCCM-BE 的黎曼控制是普通 MPC 的几何推广。

## 4. Christoffel 联络的出现

对状态相关度量 `g(z)`，变分中会出现 Christoffel 联络：

```text
Γ^k_ij = ½ g^{kl} (∂_i g_jl + ∂_j g_il - ∂_l g_ij)
```

它决定了最优路径如何随度量弯曲而变化。

## 5. 可实现性

当前代码实现了：

- 状态相关非对角度量 `g(z)`
- 控制偏差几何代价
- Christoffel 联络（数值/自动/解析）

因此理论上可以验证离散欧拉-拉格朗日方程。
