# 多区域扩展与求解器升级准备

## 1. 两区域 RC 模型设计

### 状态向量

每个区域包含空气温度和墙体温度，两个区域通过隔墙耦合：

```
x = [
  T_air_A, T_wall_A,
  T_air_B, T_wall_B,
  T_partition
]
```

共 5 个状态。若每个区域有独立外墙/外窗，可扩展到更多状态。

### 控制向量

```
u = [Q_hvac_A, Q_hvac_B]
```

每个区域一台空调，控制量为注入室内的热功率，正值加热、负值制冷。

### 外部输入

```
w = [T_out, solar_A, solar_B, occ_A, occ_B, price]
```

### 约束

- 控制边界：`Q_min_i <= Q_i <= Q_max_i`
- 舒适约束：`T_min_i <= T_air_i <= T_max_i`
- 设备约束：启停/最小运行时间可在后续加入

### 状态转移

每个区域的热平衡增加隔墙传热项：

```
C_air_A dT_air_A/dt =
  (T_wall_A - T_air_A)/R_air_A
  + (T_out - T_air_A)/R_out_A
  + (T_partition - T_air_A)/R_partition_A
  + solar_A + occ_A + Q_hvac_A
```

B 区同理。

## 2. 变量规模估算

- 预测时域 48 步
- 状态维度 5
- 控制维度 2
- 优化变量数：48 × 2 = 96
- 舒适硬约束数：48 × 2 = 96

当前单区域 48 步、1 个控制变量约 0.5～1.0 秒；两区域变量数翻倍后，SLSQP 有限差分代价会显著上升，预计不再满足强实时性。

## 3. 求解器评估

### SLSQP（当前）

- 优点：实现简单，直接支持非线性约束
- 缺点：有限差分 Jacobian 随变量数增加变慢；约束较多时迭代次数增加
- 适用：单区域 MVP、快速原型

### iLQR

- 优点：对无约束/简单约束非线性 MPC 很快，计算量随时域线性增长
- 缺点：硬约束需要额外处理，如 Augmented Lagrangian / Projected Newton
- 适用：作为热启动、或约束较少时的快速求解器

### CasADi + IPOPT

- 优点：自动微分、高效 NLP、适合带硬约束的多区域问题
- 缺点：引入外部依赖，部署体积增大
- 适用：多区域、多设备、正式产品原型

## 4. 建议路线

1. 继续用 SLSQP 完成当前单区域实验和算法验证；
2. 多区域开发时优先接入 CasADi + IPOPT；
3. 保留 SLSQP 作为后备求解器；
4. iLQR 可作为快速热启动或低约束场景的加速器。
